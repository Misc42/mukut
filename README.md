# Mukut — मुकुट, हर मोड़ पर साथ

Landing page for **Mukut** — product 02 in the [Misc42 Labs](https://misc42labs.vercel.app/) portfolio.

A clip-on safety module for any ISI-certified motorcycle helmet — dual rear cameras, live HUD, tri-radio mesh, cross-horizon SOS. v1 is being hand-built on perfboard and tested with a closed alpha of ~10 friends. Not on sale yet. No cloud, no subscription.

**Live**: <mukutsenses.com> (Vercel auto-deploys on every push to `main`).

## Files

- `index.html` — landing
- `privacy.html` — DPDP-compliant privacy policy (linked from Play Store listing)
- `vercel.json` — Vercel config: clean URLs, security headers, no build step

Source / firmware / engineering docs live in the private [Misc42/helmet](https://github.com/Misc42/helmet) repo. This public repo is intentionally only the marketing landing.

Let’s get your helmet paired.

This 90-second setup connects your phone to the helmet’s built-in WiFi and pairs the SOS button. No account, no cloud — everything runs locally between phone and helmet.

Browser compatibility
  • Chrome on Android / desktop: full experience — Web Bluetooth for SOS button pairing works.
  • iOS Safari: read-only dashboard works, but the SOS button must be paired from the Android app (iOS doesn’t expose Web Bluetooth).
  • Firefox: video + map work; Web Bluetooth is off by default.
